CREATE WITHOUT PERMISSION.

The web was built as a place to share ideas, but creativity should never need permission.

We should be free to make, experiment, remix, fail, and create something completely new.

Art does not need to be useful. Ideas do not need to be approved. Creativity does not need to follow a trend.

The internet gives everyone the ability to create, yet platforms, algorithms, and expectations can pressure us to make what is popular instead of what is meaningful.
